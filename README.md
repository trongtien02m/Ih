# Horde Evolution RPG

2.5D mobile-first Horde Evolution RPG built with Unity 6, C# and URP.

## Core gameplay
- Top-down 2.5D movement on X/Z
- Auto-target + auto-attack
- Manual active skill
- Persistent incremental progression
- Weapon mutations/evolutions/traits/fusion
- Event-driven recursive combat
- Campaign + infinite Abyss
- No offline rewards

See `docs/GAME_SPEC.md` and `docs/IMPLEMENTATION.md`.
