# Horde Evolution RPG — Canonical Summary

Mobile-first 2.5D action Horde RPG with persistent incremental progression.

- Player moves directly; weapon basic attack is automatic; one active skill is manual.
- Failure only at player HP <= 0. Earned resources are retained.
- No in-run XP choices and no offline rewards.
- One main weapon equipped.
- Persistent Global Power, weapon Mastery, Mutation, branching Evolution, Traits and Trait Fusion.
- Campaign target: 5 worlds × 20 stages, ~5 hours to Abyss.
- Abyss is infinite.
- Recursive mechanic chains are legal and constrained by technical event budgets.
- Endgame targets hundreds/thousands of hit events while danger remains readable.
- Primary weapons: Sword, Bow, Lightning Staff, Hammer, Necro Tome, Dagger.
